# 架构决策记录（ADR）

## 规则

- 编号递增：0001、0002...
- 状态：Proposed → Accepted → Superseded / Deprecated。
- 每个 ADR 必须包含背景、决策、后果。
- 新决策先写 ADR，再改代码。
- 决策被替换时更新原 ADR 状态，并关联新 ADR。
