# AI Engineering Template v0.1.0

## Purpose

将通用 AI 辅助软件开发模板固化为 v0.1.0 基线版本，提供统一的目录骨架、AI 上下文恢复、质量门与 Spec/ADR 驱动的开发流程，供 C/C++ 嵌入式、C# 工具、LabVIEW ATE、Python 自动化四类新项目复制使用。

## Completed Features

- AI context recovery
- AGENTS.md workflow
- Execution Rule
- Git baseline
- ADR mechanism
- Prompt framework
- Health Check

## Validation Result

Phase 2.7 Health Check：0 Failure / 3 Warning，3 个 Warning 由模板例外豁免；Phase 2.6 Release Checklist 全部通过。

## Known Limitations

- `language_profile`、`toolchain`、`targets`、`hardware` 为 TBD。
- build/test 报告为 `skipped`，构建与测试命令仍为 TODO 占位。
- `src/`、`tests/` 仅含占位文件，无实际测试。
- Spec-0001 为 Draft 占位模板。
- `docs/project-context.md`、`docs/architecture.md` 仍为模板占位内容。
- 复制为真实项目后，模板例外不再适用，必须配置语言 profile 并让 build/test 报告达到 `passed`。
