# Prompt: 09 Spec（需求与规格编写）

## 触发时机

新需求、功能变更或验收标准不清晰。

## 输入

- 需求描述
- 架构约束与现有 Spec

## 执行步骤

1. 按 `spec/0001-project-spec.md` 模板编写或更新 Spec。
2. 将验收标准写为可测量、可验证的条目。
3. 明确范围包含项与不包含项。
4. 登记或更新 `spec/INDEX.md`，状态置为 Review。
5. 等待用户确认后置为 Approved。
6. 按 `_checklist.md` 执行会话收尾。

## 输出

Spec 文件与索引更新。

## 约束

- Spec 未 Approved 前不开始实现。
