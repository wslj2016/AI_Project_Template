# Prompt: 07 Release（发布与归档）

## 触发时机

功能完成并准备发布。

## 输入

- 变更记录
- 当前版本号

## 执行步骤

1. 确认 Spec 验收标准全部通过。
2. 更新版本号到 `config/project.yaml`。
3. 整理发布说明与构建产物。
4. 运行 `ai-context-update.ps1` 刷新快照。
5. 创建 git tag（如项目使用）。
6. 会话结束前，按 `.ai/prompts/_checklist.md` 执行收尾。

## 输出

发布清单：版本、产物、测试结果、已知限制。

## 约束

- 未通过测试的版本不允许发布。
