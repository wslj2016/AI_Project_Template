# Prompt: 02 Plan（任务分析与方案设计）

## 触发时机

接到新任务，且未进入实现阶段。

## 输入

- 任务描述
- `spec/` 中相关 Spec（如存在）
- 当前 `status.md`

## 执行步骤

1. 确认任务与 Spec 的对应关系。
2. 列出影响面：模块、测试、文档、构建。
3. 输出实施计划：步骤、风险、验证方式。
4. 将计划更新到 `status.md` 的下一步。
5. 会话结束前，按 `.ai/prompts/_checklist.md` 执行收尾。

## 输出

简短计划，等待用户确认后再实现。

## 约束

- 计划阶段不修改 `src/` 与 `tests/`。
